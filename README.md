# SkullKing Score App

보드게임 **스컬킹(Skull King)** 점수를 라운드별로 입력하고 자동 계산하는 iOS 앱입니다.
입찰·트릭·보너스 카드·라스칼 배팅·동맹을 한 화면에서 입력하면 기본 점수와 누적 점수를 바로 보여주고, 게임이 끝나면 결과를 이미지로 공유할 수 있습니다.

## 주요 기능

- **플레이어 2~8명**, 최대 **10라운드** 진행
- 라운드마다 **입찰 / 실제 트릭 / 보너스 카드 / 라스칼 배팅 / 동맹(전리품 카드)** 입력
- 기본 점수·보너스·배팅·동맹 점수를 분리해 표시하고 누적 점수 자동 계산
- 지난 라운드를 수정하면 이후 누적 점수가 모두 다시 계산됨
- 게임 중 플레이어 추가·삭제·이름 변경·순서 변경
- 10라운드 완주 또는 중도 종료 시 **최종 결과** 화면 (우승자, 순위, 라운드별 누적 점수 그래프, 라운드 점수표)
- 결과 화면을 **이미지로 공유**하거나 **사진 앱에 저장**
- **게임 기록 보관함**: 끝난 게임 다시 보기, 중도 종료 게임 이어하기, 기록 삭제
- 앱을 다시 켜도 진행 중인 게임을 **이어하기**로 복구
- **한국어 / English** 전환 (기본값은 기기 언어)
- 규칙 시트에서 기본 규칙과 확장팩 규칙 확인

## 점수 규칙

### 기본 점수

| 상황 | 점수 |
|---|---|
| 입찰 성공 | 입찰 트릭 × 20 |
| 입찰 실패 | 차이 × −10 |
| 0 입찰 성공 | 라운드 번호 × 10 |
| 0 입찰 실패 | 라운드 번호 × −10 |

### 보너스 카드 (입찰에 성공했을 때만 반영)

| 카드 | 점수 |
|---|---|
| 일반 14 (노랑·초록·보라) | +10 / 장 |
| 검정 14 | +20 / 장 |
| 해적이 인어 획득 | +20 / 장 |
| 스컬킹이 해적 획득 | +30 / 장 |
| 인어가 스컬킹 획득 | +40 |
| 확장 숫자 8 | 트릭 승리 시 +5 / 장 |
| 확장 숫자 7 | 트릭 승리 시 −5 / 장 |
| 스컬킹·인어가 일등항해사 콘 획득 | +30 |
| 데이비 존스의 사물함이 바다괴물 파괴 | +20 / 장 (**입찰과 무관**) |

> 일부 판본은 인어가 스컬킹을 잡으면 +50점입니다. 사용하는 규칙에 맞게 `ScoreRules`와 `RoundEntry.bonusPoints`를 조정하세요.

### 라스칼 배팅

- 0 · 10 · 20점 중 선택
- 입찰 성공 시 +배팅, 실패 시 −배팅

### 동맹 (전리품 카드)

- 두 플레이어를 동맹으로 묶으면 **둘 다 입찰에 성공했을 때** 각자 +20점
- 한 라운드에 여러 동맹을 등록할 수 있음

## 지원 확장팩

규칙 시트에 다음 확장 카드의 규칙이 정리돼 있고, 점수에 영향을 주는 카드는 입력 항목으로 제공됩니다.

- 확장 숫자 7(−5) · 8(+5)
- 와일드 15
- 메리 손 (새 해적)
- 마지막 일격
- 판자 위를 걸어라
- 점박이 가오리
- 데이비 존스의 사물함
- 일등 항해사 콘

## 화면 구성

| 화면 | 설명 |
|---|---|
| 게임 설정 | 게임 이름, 플레이어 등록, 이어하기 카드, 기록 보관함·규칙 진입 |
| 라운드 입력 | 플레이어별 입력 카드, 동맹 섹션, 라운드 이동, 저장 후 다음 라운드 |
| 점수표 | 라운드별 입찰·실제·기본·보너스·배팅·누적 |
| 최종 결과 | 우승자, 순위, 누적 점수 그래프(Swift Charts), 라운드 점수표, 공유·저장 |
| 게임 기록 | 저장된 게임 목록, 결과 보기, 이어하기, 삭제 |
| 규칙 | 기본 규칙 표, 확장팩 카드 설명 |

## 기술 스택

- Swift / SwiftUI
- Swift Charts (누적 점수 그래프)
- Observation (`@Observable` 언어 설정)
- ImageRenderer + UIActivityViewController (결과 이미지 공유)
- Photos (사진 앱 저장)
- UserDefaults + Codable (게임 상태·기록 저장)
- 외부 라이브러리 없음

## 요구 사항

- iOS 26.2 이상 (iPhone · iPad)
- Xcode 26 이상

## 빌드

1. 리포를 클론합니다.
2. `SkullKing.xcodeproj`를 Xcode로 엽니다.
3. 서명 팀을 본인 계정으로 바꾼 뒤 기기 또는 시뮬레이터에서 실행합니다.

## 프로젝트 구조

```
SkullKing/
├── SkullKing.xcodeproj
└── SkullKing/
    ├── ContentView.swift   # 모델·점수 규칙·모든 화면 (단일 파일)
    └── Assets.xcassets     # 앱 아이콘, 액센트 색
```

`ContentView.swift` 안의 주요 구성:

| 구분 | 타입 |
|---|---|
| 모델 | `Player`, `RoundEntry`, `Alliance`, `RoundRecord`, `RoundResult`, `SavedGame`, `AppSave` |
| 점수 규칙 | `ScoreRules` (상수·기본 점수·보너스·동맹 계산) |
| 언어 | `AppLanguage`, `LanguageStore`, `tr(_:_:)` |
| 화면 | `ContentView`, `PlayerSetupView`, `PlayerEntryCard`, `AllianceRow`, `RoundScoreTable`, `ScoreTableSheet`, `FinalResultView`, `HistoryView`, `RulesSheet` |

## 데이터 저장

- 현재 게임과 기록 보관함을 `AppSave` 하나로 묶어 UserDefaults(`SkullKingScoreApp.Save.v3`)에 JSON으로 저장합니다.
- 입력 원본(`RoundRecord`)을 저장하므로 과거 라운드 수정과 이어하기가 가능합니다.
- 이전 버전(v2) 저장본은 보관함만 가져오고 삭제합니다.
- 새 필드는 `decodeIfPresent`로 기본값을 채워 이전 저장본과 호환됩니다.
